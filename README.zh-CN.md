# ADB GUI Tool

一个功能强大（？）的 GUI ADB 工具，使用 Python + PyQt5 编写。

> [!NOTE]
> 🌐 当前仅支持中文界面。

## 环境要求

- Python 3.7+
- PyQt5
- ADB (Android Debug Bridge)

## 当前支持情况

- **宿主机操作系统**: macOS 15（主要开发环境）  
  *Windows 和 Linux 支持已规划，但尚未进行全面测试。*
- **已测试的目标 Android 版本**: Android 11, Android 7

## 功能特性

- **设备管理**
  - 自动检测并手动刷新已连接设备（USB / 网络）
  - 设备别名、收藏夹、连接历史记录
  - 拖拽排序设备列表
- **设备信息**
  - 型号、Android 版本、电池状态、屏幕分辨率、IMEI、MAC 地址、蓝牙、开机时间、CPU、内存、存储空间
  - 实时属性转储 (`getprop`)
- **应用管理**
  - 列出系统应用和用户应用，显示应用图标（异步缓存）
  - 搜索 / 过滤（支持普通文本和正则表达式）
  - 拖拽安装 APK、卸载、清除数据、导出 APK
  - 以普通方式或以 root 权限启动应用
- **文件管理**
  - 双面板布局（目录树 + 文件表格）
  - 上传、下载（带进度条）、删除、重命名、新建文件夹
  - 按键快速定位文件、显示/隐藏隐藏文件
- **日志查看器**
  - 实时 logcat 输出，支持按级别过滤 (V/D/I/W/E/F)
  - 搜索高亮、暂停/恢复滚动、保存到文件
- **进程管理**
  - 查看正在运行的进程，结束选中进程
  - 复制 PID 或进程名，可调整刷新间隔
- **交互式终端**
  - 完整的 `adb shell` 终端，支持命令历史记录
- **内置软键盘**
  - 标准按键布局 + 所有 Android KeyEvent 常量（按类别分组）
- **广播发送器**
  - 发送任意 `am broadcast` 命令，支持附加 extra 参数
- **代理设置**
  - 查看、设置和清除设备的全局 HTTP 代理
- **工具栏快捷操作**
  - 截图、屏幕录制、重启（系统 / Recovery / Bootloader）、关机
  - root / unroot 管理、重新挂载 `/system`、查看分区挂载
  - Monkey 测试、tcpdump 抓包、沉浸模式切换
- **全局设置**
  - 可配置 ADB 和 scrcpy 路径
  - 语言选择（中文 / 英文）—— *参见已知问题*
  - 可自定义常用操作的键盘快捷键
  - 清除缓存、恢复默认设置

## 已知问题

- **多语言支持尚未生效。**  
  翻译框架 (`QTranslator`) 和 `.qm` 文件已准备就绪，所有 UI 字符串均已使用 `self.tr()` 包裹。但目前切换语言后界面文本并不会实际替换，正在排查原因。

- **Windows / Linux 兼容性尚未测试。**  
  路径处理、ADB 查找方式以及快捷键设置可能需要在非 macOS 系统上进行适配。

- **部分功能为占位或实验性的：**
  - 文件管理器的前进/后退导航尚未实现。
  - 屏幕录制在设备不支持 `screenrecord` 或进程卡住时可能失败。
  - IMEI 获取并非在所有设备上都保证成功（需要权限或 root）。
  - tcpdump 抓包假定设备上已安装 `tcpdump` 且已获取 root 权限。

- **在老设备（如 Android 7）上性能可能较慢**，主要由于应用列表加载时的图标提取方式。
